我喜欢观察问题、做产品、创办公司，也习惯把想法做出来，再从真实的反馈中学习。我的工作主要围绕 AI 应用、SaaS、移动应用，以及帮助创业者推进产品和业务的工具与社区。

2016 年，我上线了一个面向作者和读者的小说阅读网站。后来做过校园交易平台，开发过移动应用和网站，联合创办过音乐创业公司，也作为创始人参加了 Techstars 和 Georgia Tech CREATE-X。

对我来说，做产品是一个完整的过程：理解问题、设计体验、开发上线，再找到真正需要它的人。工作之外，我喜欢旅行、摄影和写作。
